Recovery runbook

Restore service in three steps

01 · VERIFYOpen CI and check whether the latest runtime tests and webapp build passed. Identify the failing commit before changing code.
02 · RECOVERPull the latest main branch locally. Review git status first; resolve conflicts deliberately and never force-push to bypass them.
03 · VALIDATERun the documented tests, start the runtime and webapp, then verify API health before returning to normal use.
