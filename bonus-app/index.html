Relationship semantics

Shared category or interface pattern indicates functional overlap only. SysCentre does not infer that one repository imports, calls, deploys or controls another unless that relationship is documented and verified.

Recovery runbook

Verify, recover, then validate.

01 · VERIFY

Open CI and identify the failing check and commit. Confirm whether the problem is the static site, local API, indexer or an individual source project.

02 · RECOVER

Pull the correct branch locally, review working-tree changes, and use each project's own documented recovery steps. Do not force-push over remote history.

03 · VALIDATE

Run the project's tests, verify its own health endpoints and inspect its UI. Re-index source metadata only after the correct repository mapping is confirmed.
